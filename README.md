# Attendance Tracking Automation

## Project Overview

An automated student attendance management system built with n8n and Google Sheets to simplify attendance tracking, monitor student participation, and identify students who need follow-up.

## Problem

Manually tracking attendance, calculating attendance percentages, and identifying repeated absences can be time-consuming and prone to errors.

## Solution

I built a workflow that processes attendance records, calculates attendance statistics, detects consecutive absences, and flags students who fall below the required attendance threshold.

## Key Features

* Automated attendance record processing
* Student attendance percentage calculation
* Consecutive absence detection
* Email alerts for students who miss two consecutive classes
* Management review flag for attendance below 80%
* Duplicate attendance prevention

## Tools Used

* n8n
* Google Sheets
* n8n Forms
* Email automation
* JavaScript for workflow logic

## How It Works

1. An instructor submits attendance.
2. The workflow processes the submitted records.
3. Attendance data is stored in Google Sheets.
4. The system calculates attendance statistics.
5. Consecutive absences trigger email notifications.
6. Students below the attendance requirement are flagged for management review.

## Testing and Improvements

I tested the workflow with different students, attendance records, and programme durations. During testing, I identified and corrected attendance calculation issues and improved the workflow to prevent duplicate records.
